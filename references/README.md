# Reference policy

This directory records source provenance; it is not a paper redistribution folder.

- Public metadata, BibTeX, links, hashes, and short fair-use notes may be committed.
- Copyright-restricted full texts belong in `references/private/` and are ignored by Git.
- External code is never copied until its license and exact revision are recorded.
- Digitized figure data must record source figure, axes, access date, and digitization error.

See `docs/source_manifest.md` for the canonical ledger.

`references.bib` is the committed working bibliography. Bibliographic presence does not
mean the full text was available; consult the source manifest before using a source for an
implementation equation or claim.
